# scrcpy master

GUI-лаунчер для [scrcpy](https://github.com/Genymobile/scrcpy) на Python +
CustomTkinter. Рассчитан на **scrcpy 1.25** — набор опций в интерфейсе
намеренно ограничен тем, что поддерживает эта версия.

## Установка

```bash
pip install -r requirements.txt --break-system-packages   # или в venv без флага
python3 main.py
```

Нужны установленные `adb` и `scrcpy` в PATH (либо укажите полный путь к ним
в полях слева внизу и нажмите «Сохранить пути»).

## Возможности

- Список устройств (`adb devices -l`) с автообновлением, статус online/offline.
- Подключение по Wi-Fi: включение TCP/IP для уже подключённого по USB
  устройства, подключение по `ip:port`, беспроводное сопряжение Android 11+
  (`adb pair`) без предварительного USB.
- Профили настроек: любое количество профилей, каждый — независимый набор
  флагов scrcpy; создание, клонирование, удаление.
- Несколько одновременных сессий scrcpy (например, телефон + планшет) —
  каждая сессия отслеживается по своему PID, «Остановить» останавливает
  только сессию текущего выбранного устройства, а не все scrcpy в системе.
- Поле «Доп. аргументы» в любом профиле — для флагов, которых нет в форме.

## Сознательно не реализовано (нет в scrcpy 1.25)

Эти флаги появились в более поздних версиях scrcpy — добавлять их в форму
сейчас не имеет смысла, они просто приведут к ошибке "unknown option":

- выбор видеокодека `--video-codec` (h265/av1/vp8/vp9) — добавлено в 2.0/4.1;
- аудио `--audio-*` / `--no-audio` — добавлено в 2.0;
- камера `--video-source=camera`, `--camera-*` — добавлено в 2.2;
- UHID-клавиатура/мышь `--keyboard=uhid` / `--mouse=uhid` — добавлено в 2.4
  (в 1.25 доступны только старые `--hid-keyboard`/`--hid-mouse`, Linux+USB);
- `--no-display` (запись без окна) — не проверено на 1.25, не включено.

Если обновите scrcpy до 2.x — дайте знать, добавлю эти секции в форму.

## Структура проекта

| Файл | Назначение |
|---|---|
| `config.py` | Модель профиля, загрузка/сохранение JSON-конфига |
| `adb_utils.py` | Обёртки над `adb` (список устройств, tcpip, pair) |
| `runner.py` | Сборка аргументов scrcpy из профиля, процесс-менеджер |
| `gui.py` | Интерфейс CustomTkinter |
| `main.py` | Точка входа |

Конфиг хранится в `~/.config/scrcpy-master/config.json`.
